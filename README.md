# LenderCheck

> Verify any loan app in 10 seconds, before it verifies you.

## Description

A Telegram-based loan app verification prototype built for RBI Hackathon 2026.

## Tech Stack

- **React**
- **Vite**
- **Lucide React**

## How to Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Disclaimer

> **Note:** This is a demo prototype — all data is simulated, no real API calls or backend.
